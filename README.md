# NumPy Practice

A collection of Jupyter notebooks documenting my practice and learning of NumPy, a Python library for numerical computing.

## Topics Covered

- Creating NumPy arrays, vectors, and matrices
- Array attributes, indexing, and slicing
- Reshaping and manipulating arrays
- Built-in array operations and broadcasting
- Aggregate functions and statistical operations
- Conditional selection and sorting
- Stacking and combining arrays
- Random number generation

## Tools Used

- Python
- NumPy
- Jupyter Notebook

## Purpose

These notebooks are part of my Python learning journey and help me build a foundation in numerical computing and array manipulation for future data analysis work.
